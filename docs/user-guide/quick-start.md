\# Быстрый старт



Добро пожаловать в TaskTracker!



\## 1. Создание учетной записи



Перейдите на \[сайт приложения](https://app.tasktracker.example.com) и нажмите \*\*"Зарегистрироваться"\*\*.



\## 2. Создание первой задачи



После входа в систему:

1\. Нажмите кнопку \*\*"Новая задача"\*\* в верхней панели.

2\. Заполните поля:

&#x20;   \* \*\*Название:\*\* "Проанализировать требования"

&#x20;   \* \*\*Описание:\*\* "Собрать и задокументировать требования к новому модулю"

&#x20;   \* \*\*Исполнитель:\*\* Выберите себя из списка.

3\. Нажмите \*\*"Создать"\*\*.



\## 3. Что дальше?



\* Ознакомьтесь с подробным руководством по \[работе с задачами](./tasks.md).

\* Изучите \[возможности API](../api/overview.md) для автоматизации.
